## Compatibility amendment after floor verification

The planned 3.5.0 minimum is superseded by **3.8.0 for both core and the Vue adapter**. Real-router tests found that 3.5.0 compares `onHttpException` and `onNetworkError` when matching prefetched requests. Visit callbacks and prefetch defaults therefore produce different cache keys, even with the preserved microtask scheduling. One click sent two HTTP requests on both Vuetify majors; cancelling those outstanding prefetches also exposed the older unhandled cancellation rejection. A mixed direct core 3.8.0 / Vue adapter 3.5.0 fixture reproduced the same issue because the adapter owns the router and its nested core.

[Upstream commit 01a06f7c653f469a94f254e89587d1bddfa913bf](https://github.com/inertiajs/inertia/commit/01a06f7c653f469a94f254e89587d1bddfa913bf) excludes these callbacks from prefetch equality as part of the Link/Form callback update. Tag containment and v3.7.1 source confirm **v3.8.0 is the first published fix**. Raising both minimums is the smallest released dependency change that supports callback forwarding together with existing click-prefetch reuse. No local cache-key workaround is added.

Additional finding: `prefetch-error-callback-identity` — **implemented** by requiring Inertia 3.8.0, the first released fix, in both dependency constraints. Verified 25 tests on Inertia 3.8.0 with Vuetify 3.5.14/Vue 3.3.0 and Vuetify 4.0.0/Vue 3.5.0. Local evidence: `package.json`, `package-lock.json`, and `tests/integration.test.js` (click-prefetch reuse). The earlier floor/mixed fixtures remain recorded as evidence of why those versions are excluded.

The integration suite also required `vitest.config.js` to inline Vuetify so Vitest handles its CSS imports. Fresh temporary fixture installs hit an npm 10.9.9 Arborist `edgesOut` exception while expanding Vitest's optional peer graph. Seeding fixtures from this repository's lockfile and resolving only the selected version changes completed normal peer-checked installs; no `--force` or `--legacy-peer-deps` was used.
